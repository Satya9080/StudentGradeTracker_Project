# 🎓 Student Grade Tracker

A Java-based desktop application for managing student academic records and calculating grades automatically.

## 📌 About the Project

Student Grade Tracker helps teachers or administrators manage student information, subject-wise marks, and academic performance in one place.

The application automatically calculates the total marks, percentage, grade, and final result based on the entered marks.

## ✨ Features

- 🔐 Login System
- 👨‍🎓 Add Student
- 📋 View Student Records
- 🔍 Search Student
- ✏️ Edit Student Details
- 🗑️ Delete Student Records
- 📝 Enter Subject Marks
- 🧮 Automatic Total & Percentage Calculation
- 🏆 Automatic Grade Calculation
- ✅ Pass/Fail Status
- 💾 File-Based Data Storage
- ⚠️ Input Validation & Exception Handling

## 🛠️ Technologies Used

- Java
- Java Swing
- OOP
- ArrayList
- JTable
- File Handling
- Exception Handling

## 📊 Grade Calculation

| Percentage | Grade |
|-----------|-------|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| 40–49 | E |
| Below 40 | F |
